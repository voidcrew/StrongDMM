STRONGDMM VOIDCREW - WINDOWS X64
Version: 0.1.0

START
1. Extract the whole ZIP into a writable folder.
2. Use a test branch or separate copy of your Voidcrew repository.
3. Double-click StrongDMM.exe, click Open Project, and select tgstation.dme.
   You can also drag a project folder, .dme, or .dmm onto StrongDMM.exe.
4. Open Ship Workshop or New Ship from the project page or Voidcrew menu.
   Open Map and New Map use the normal StrongDMM editor.

The game repository and its icons/maps are required and are not included.
No Go, Rust, BYOND or existing StrongDMM installation is needed to run the
editor. Compiling and playing the game still require the game's usual tools.
This build needs 64-bit Windows and a graphics driver supporting OpenGL 3.3.

TRY AN EXISTING SHIP
- Pick a hull, theme and module loadout.
- Use View or Ctrl+1/2/3/4 to toggle areas, turfs, objects and mobs.
  Ctrl+2 hides floors to reveal piping underneath. Pipes and cables follow
  normal object visibility; there is no separate Utilities checkbox.
- Under Editing, choose Hull or a module, then use the normal mapping tools
  directly on the assembled canvas. Only that source is editable.
- Make a small edit, switch modules/themes and return: the edit should remain.
- Try undo/redo after switching sources. The correct source should activate.
- Save all ships, close/reopen, and inspect the source files in Git.
  A module-only edit should not rewrite the hull.
- Source alone shows the active map without the assembled context.

CREATE A SHIP
- Click New ship..., enter a unique lowercase ID, a name and canvas dimensions.
  A new ship begins with an empty canvas and a docking port.
- Select Hull, expand Build, set Left/Bottom/Right/Top and click
  Lay permanent deck. This creates flooring with the ship's own area.
- Map a room. Use the Grab selection tool and Use selection bounds, or enter
  room bounds directly. Enter a slot ID/name and click Extract upgrade slot.
- Select the resulting module under Editing and try changing its contents.
  Clone module / New empty alternative create choices for that slot.
- Enter a new ID/name and Clone theme to create separate hull/module maps.
- Try undo/redo across extraction, painting and theme creation.
- Review Ship settings and Save preview, then Save all ships.
  New ships default to Development only and stay off the player purchase list.

SAVE BEHAVIOR
Saving writes into the checkout you selected. A new ship creates .dmm maps,
its hull/module/theme registrations, a .ship.json project file and .dme
includes. Save all ships saves every ship opened in this workshop session.
Files edited elsewhere after opening are checked before replacement.
Close ordinary map tabs before opening those same sources in Ship Workshop.

CURRENT LIMITS
Single-deck prototype. Existing hand-authored ships support source-map editing;
the Build and Ship settings authoring controls apply to workshop-created ships.
Preview PNG generation, BYOND compilation and gameplay tests are separate.
The editor's static checks do not establish that a ship is playable.
The executable is unsigned.

CHECK SAVED MAPS
The optional shipcheck.exe command-line utility checks default loadouts and
each alternative module against the other defaults, not every permutation.
It only reads saved maps. From a terminal, run:
  shipcheck.exe -dme "path\to\tgstation.dme" -all > shipcheck.json
Static warnings may already exist in the current fleet; compare before/after.

IF IT CLOSES AT STARTUP
StrongDMM.exe reports startup failures in a Windows dialog with the location
of a session log. That log captures the editor output and crash details.
Logs are local and are never uploaded automatically. You can also open the
log folder from Help > Open Logs Folder. Cancelling project selection returns
you to the editor's project page.
